What is Vortexia Bot?

Vortexia Bot is an independent, free Discord bot that replaces a stack of single-purpose bots. Add it once and your server gets a Lavalink-powered music player, moderation commands, ticket panels, an economy and level system, an embed builder, and everyday utility commands.

Everything is controlled with Discord slash commands — type / in any channel to see what Vortexia can do. Core features have no premium paywall.

What can Vortexia Bot do?

  • Music bot — queue, filters, lyrics, loop modes and 24/7 voice mode.
  • Moderation bot — ban, kick, timeout, warn, purge, lock and slowmode.
  • Ticket bot — button panels that open private support channels.
  • Economy & levels bot — coins, daily rewards, ranks and leaderboards.
  • Utility — embed builder, dashboard, user and server info.

How to add Vortexia Bot to your Discord server

  1. Click Add to Discord.
  2. Choose your server and authorize the permissions.
  3. Type /help or /music in a channel to start. The full list is on the commands page.
