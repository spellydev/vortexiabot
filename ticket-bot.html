How the Vortexia ticket system works

Run /ticket setup to post a panel. Members click the button to open a private ticket channel; staff reply, add users and close the ticket when done.

Ticket commands

  • /ticket setup (optionally with name:Support)
  • /ticket add user:@User
  • /ticket close

Set up tickets

  1. Add Vortexia Bot.
  2. Choose the channel for your support panel and run /ticket setup.
  3. Members click the button to open a ticket.

FAQ

Is the Vortexia ticket bot free?

Yes, tickets are part of the free core features.

How do I create a ticket panel?

Run /ticket setup in the channel where you want the panel.

Can staff add someone to a ticket?

Yes, use /ticket add user:@User inside the ticket channel.
