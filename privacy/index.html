Privacy Policy

This policy explains what Vortexia Bot processes when it is used in Discord servers, why that information is needed, where it may go, and how people can request deletion.

Effective date: 18 November 2026 · Applies to Vortexia Bot and the Vortexia website.

Important: Vortexia is a third-party Discord application. Discord separately processes account and platform data under Discord’s Privacy Policy. This policy covers Vortexia’s own processing.

1. Who operates Vortexia

Vortexia Bot is maintained by its independent developer, identified on the website as Spelly. For privacy questions or data requests, contact the maintainer through the official Vortexia Support Server. Do not send passwords, authentication tokens, or other secrets.

2. Information Vortexia processes

Depending on which features a server administrator enables and which commands a person uses, Vortexia may process:

  • Discord identifiers and basic profile data: user, server, channel, role and message IDs; usernames or display names; avatars and member metadata exposed by Discord.
  • Server configuration: moderation settings, automod rules, welcome settings, role/channel IDs, ticket settings, custom responses, logs configuration and other administrator-selected options.
  • Feature records: warnings, AFK status/reason, leveling XP, economy balances, invite attribution/history, giveaway or ticket state, and command-use counters where those features are used.
  • Support and privacy requests: information you choose to provide when contacting the support team.
  • Website technical data: standard request information processed by the static hosting/CDN provider, such as IP address, user agent and request time, subject to that provider’s settings and policy.

Vortexia does not ask for Discord passwords or account authentication tokens. Never share them with the bot or support team.

3. Message Content and how it is used

When the Message Content privileged intent is enabled in the Discord Developer Portal and in the bot runtime, Vortexia can receive message text and certain message fields for specific features. The current codebase uses message content for:

  • Custom AutoMod: evaluate configured spam/repetition, invite-link, URL, excessive-caps, emoji-flood, banword, spoiler and long-message rules so configured moderation actions can run.
  • Custom auto-responses: compare a message against server-configured triggers and send the matching response.
  • Vortexia AI: respond when a user deliberately mentions the bot or replies to it. Relevant prompt text, and an image attachment when selected by the feature, may be sent to the AI provider configured by the operator to generate a response.
  • Button-initiated paste input: read a value that a user intentionally submits after opening a bot workflow; the handler attempts to delete that submitted message after processing.
  • Leveling anti-farming: when a server enables leveling, message text is checked for meaningful, non-repeated conversation before XP is awarded.
  • Deleted/edited message recovery: the bot keeps a limited in-memory snipe record for the latest deleted or edited message in a channel.

AutoMod spam windows, leveling anti-farming comparisons, snipe records and AI conversation context are held in process memory and are cleared on restart/session eviction. The reviewed code does not write these ordinary message-text buffers to its JSON data files. However, if a server administrator configures an AutoMod log channel, Vortexia may include up to 900 characters of the triggering message in the moderation log embed posted to that Discord channel. That log message is then subject to the server’s own Discord retention and moderation controls. Other feature records listed above are stored in the bot operator’s data directory.

Vortexia does not use Discord API message content to train its own machine-learning models. AI prompts are sent only to the AI provider configured by the bot operator for inference, not for Vortexia model training.

The Message Content intent is not used to read every server message for advertising, profiling, sale, or unrelated analytics. It is used to provide the features listed above in servers where the bot is installed and the relevant feature is enabled.

4. Third-party services and sharing

Vortexia does not sell Discord API Data or provide it to advertising/data-broker services. Data may be processed by:

  • Discord: the platform through which bot commands, events and messages are delivered.
  • Hosting provider: the infrastructure operator hosting the bot and/or website, which may process operational logs and stored bot data.
  • Configured AI provider: a provider such as Gemini, Groq, Cloudflare Workers AI or OpenRouter, depending on the operator’s configuration, receives a prompt only when the AI feature is invoked.
  • Configured web-search provider: when AI web search is enabled, the configured search service (such as Tavily, Brave or Serper) may receive the search query.
  • Feature APIs: external services used by a specific utility command (for example weather, translation, lookup or media information) may receive the query needed to return the requested result.

Those services operate under their own terms and privacy policies. The bot operator should keep its provider configuration and this list current when changing vendors.

5. Storage and retention

Persistent bot feature data is stored in JSON files in the bot operator’s configured data directory on the hosting environment. The reviewed code includes persistent records for server settings, warnings, AFK data, invite history, tickets, leveling configuration and related feature state. Retention depends on the feature, server configuration, available reset controls and the operator’s hosting/backups. The current package does not define one universal automatic deletion period for every stored record.

Short-lived message-processing buffers and AI conversation context are held in memory rather than the persistent JSON data store and are cleared when the process restarts or the relevant in-memory session is evicted. Website/CDN logs are controlled by the hosting provider’s retention settings.

Removing the bot from a server does not necessarily erase previously saved data files or hosting backups. A deletion request is therefore the appropriate route for requesting removal of Vortexia-held records.

6. Your choices and deletion requests

  • Server administrators can disable the relevant Vortexia feature, remove the bot, or use available feature reset controls.
  • Users or server administrators can request deletion of Vortexia-held records by contacting the maintainer through the official support server.
  • Include the relevant Discord user ID and/or server ID, the feature involved, and a brief description of the requested deletion. Do not post sensitive information publicly; ask for a private support channel.
  • The maintainer may need to verify that the requester controls the relevant account or server before processing a request. Some records may need to be retained where required for security, dispute resolution or legal obligations.

Requests relating to data held by Discord itself must be made to Discord through its own privacy tools and policies.

7. Security

The bot package uses local data files and runtime configuration. Operators should restrict host and file access, keep dependencies updated, use environment variables for secrets, limit staff access to logs, and maintain secure backups. No internet-connected service can guarantee absolute security; report suspected unauthorized access promptly through the support server.

8. Children

Vortexia is designed for use within Discord and is not directed to children below the minimum age required to use Discord in their jurisdiction. Do not use Vortexia to collect sensitive personal information.

9. International processing

Hosting and configured third-party providers may process information in countries other than yours. Their applicable safeguards and terms govern those services.

10. Changes

This policy may be updated when bot features, data flows or legal requirements change. The effective date at the top will be updated when material changes are made. Continued use after an update means the updated policy applies to future use.

11. Contact

Privacy contact: Vortexia Support Server. Ask for a private channel for account-specific requests.
