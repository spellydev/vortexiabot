01 · Getting started

Set up Vortexia in a few steps

You do not need to enable every feature at once. Start with the commands your community needs.

Step 1 · InviteUse the official invite link and select your Discord server. Review the permissions requested by the bot.
Step 2 · CheckRun /ping in a server channel. Then use /help to see the available slash commands.
Step 3 · ConfigureChoose a system such as welcome, tickets, verification or moderation and follow its setup command prompts.
Tip: Slash commands appear when you type / in Discord. Prefix commands start with ?, while V-Game commands start with v.
02 · Command types

Know which command format to use

/

Slash commands

Type /, choose Vortexia’s command from Discord’s menu, then fill in the fields displayed. Many commands use subcommands such as setup, status or disable.

?

Prefix commands

Type the command with its ? prefix, followed by any required text or member. Example: ?weather London.

V

V-Game commands

Type v followed by the game action. Example: v daily, v hunt or v profile.

🔒

Private owner commands

Some management controls are restricted to the configured bot owner and intentionally do not appear in public help.

03 · Before you run commands

Permissions & common issues

Missing permissions

Give Vortexia the Discord permissions required by the feature. A moderator command also requires the person running it to have the relevant permission.

Role hierarchy

Vortexia’s highest role must be above roles it needs to assign or manage. Discord prevents bots from managing roles above their own highest role.

Command not visible

Check that the bot was invited with the applications.commands scope. Newly registered slash commands may take time to appear.

Command failed

Read the bot’s reply, check required options, verify channel/role permissions, then retry. For help, join the support server.

05 · Restricted

Private owner tools

?adminBot owner only

Private owner-only management menu for server, status, economy, command-log and stats-board controls. This command is not available to regular server members and is intentionally omitted from the public command catalogue.

Usage: only the configured bot owner can run ?admin.

System guide

Moderation & safety

Use temporary moderation commands, AutoMod, banned-word filters, strikes and event logs to help keep a server safe. Always verify the target and reason before applying an action.

Server setup & roles

Configure welcome and goodbye messages, boost announcements, reaction roles, verification, VoiceMaster and server statistics. Setup commands ask you to select the relevant channel or role.

Tickets & giveaways

Create ticket panels for support requests. Staff can claim, close, rename or manage ticket participants. Giveaways support interactive entry and management controls, subject to each giveaway’s settings.

Music

Join a voice channel, open the music player and use its interactive controls to search, select and manage tracks. The player controls are shown after you run the music command.

Economy & V-Game

V-Game uses the v prefix for activities, collection, social interactions and mini-games. Some advanced systems may be placeholders or have limited persistence in this build; check the bot response for the exact behavior.

Utilities & fun

Quick prefix commands include server/member information, converters, lookups, reminders, jokes, memes and lightweight games. External lookup commands depend on the relevant third-party service being available.
