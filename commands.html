COMMANDS

TYPE /
AND GO.

Search and filter commands. Copy the example and paste it into Discord.

/musicMusic

Open the full music player panel in the current channel.

How to useJoin a voice channel, then type /music. Use the buttons to play, pause, skip, loop and open the queue.
/playMusic

Search and play a track or playlist from the player.

How to useOpen /music, press Play, or use search on the panel. Supports YouTube, Spotify links and queries.
/queueMusic

View and manage the current song queue.

How to useFrom the music panel click Queue, or use the queue button to see upcoming tracks and reorder.
/lyricsMusic

Show lyrics for the current track when available.

How to useWhile a song is playing, open the panel and tap Lyrics — or run the lyrics action from controls.
/247Music

Keep the bot in voice 24/7 even when the queue is empty.

How to useEnable 24/7 mode from the music panel. The bot stays connected until you disable it.
/banModeration

Permanently ban a member from the server.

How to use/ban user:@User reason:spam — optional reason is stored in audit logs.
/kickModeration

Remove a member without banning them.

How to use/kick user:@User reason:breaking rules
/timeoutModeration

Temporarily mute a member (Discord timeout).

How to use/timeout user:@User duration:10m reason:spam — use m/h/d for time.
/warnModeration

Issue a formal warning to a member.

How to use/warn user:@User reason:inappropriate language
/purgeModeration

Bulk-delete recent messages in a channel.

How to use/purge amount:50 — max depends on Discord limits (usually up to 100).
/lockModeration

Lock a channel so members cannot send messages.

How to use/lock channel:#general — unlock the same way when ready.
/slowmodeModeration

Set slowmode delay on a channel.

How to use/slowmode channel:#chat seconds:10
/ticket setupTickets

Create a support ticket panel with buttons.

How to use/ticket setup name:Support — post the panel in a channel members can see.
/ticket closeTickets

Close the current ticket channel.

How to useRun inside a ticket channel: /ticket close. Staff can add a reason if prompted.
/ticket addTickets

Add a user to an existing ticket.

How to use/ticket add user:@User inside the ticket channel.
/balanceEconomy

Check your coin balance (or another member’s).

How to use/balance or /balance user:@User
/dailyEconomy

Claim your daily coin reward.

How to useType /daily once every 24 hours. Streaks may boost the reward.
/rankEconomy

Show your level card and XP progress.

How to use/rank or /rank user:@User — levels rise from chat activity.
/leaderboardEconomy

View top members by coins or levels.

How to use/leaderboard — switch between economy and levels if the bot offers tabs.
/payEconomy

Send coins to another member.

How to use/pay user:@User amount:100
/embedUtility

Open the live embed builder.

How to use/embed — set title, description, color, image, then send to a channel.
/dashboardUtility

Open the in-Discord control dashboard.

How to use/dashboard — manage modules and settings from panels.
/helpUtility

List commands or get help for a specific one.

How to use/help or /help command:music
/userinfoUtility

Show info about a user (join date, roles, ID).

How to use/userinfo user:@User
/serverinfoUtility

Show stats about the current server.

How to use/serverinfo
